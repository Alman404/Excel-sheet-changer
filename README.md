# Excel-sheet-changer
Created this python project, it can search out any values in excel and can do almost any functionality in it

It uses python packages to execcute this code.

We are using "openpyxl" a python library, that helps you get access to your any downloaded excel sheet file

This program adds a new column to your excel sheet, and performs an operation by multiplying different values by7 *0.9

The code also generates a "BarChart", of the data you have gathered.

Although you can generate many types of Chart, its not compulsory or necessary to only generate a BarChart
